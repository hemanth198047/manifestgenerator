Step 1: Sources

{{banner}}

Add SQL, CSV, TSV, TXT, Markdown or OpenAPI JSON sources. Each source needs a file name with its extension so the format can be recognised. Spreadsheets (XLSX, XLS), Word (DOCX), PDF and HTML need optional reader adapters; the capability list on the home page shows which are installed here. Where one is missing, export to CSV, TSV, text or Markdown first. Nothing is executed, and row values from data files are not kept.
