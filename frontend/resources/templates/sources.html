Add SQL, CSV, TSV, TXT or Markdown sources. Each source needs a file name with its extension so the format can be recognised. XLSX, DOCX, PDF and HTML are not supported in this dependency-free build; export them to CSV, TSV, text or Markdown first. Nothing is executed, and row values from data files are not kept.
